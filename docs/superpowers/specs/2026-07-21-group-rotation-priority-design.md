# 分组轮换优先级设计

## 目标

分组重建后，轮换从总剩余额度最高的组开始，避免分组求解器的内部桶顺序决定请求调度顺序。

## 范围

- 保持现有分组算法、分组大小和组内 Key 的加权选择不变。
- 在 `optimalGroups` 返回组状态后，为组间轮换建立确定顺序：总剩余额度降序。
- 两组总余量相同时，按 `SHA-256(年月 + 有序组内 Key 名称)` 升序比较；哈希相同才按成员名的字典序比较。
- 月度切换时将首个活动组重置为索引 0。相同配置在同一个月重启时得到相同首组，跨月时排序自然变化，不需要任何持久化状态。

## 验证

在 `internal/pool/pool_test.go` 增加回归测试：总余量不同的组仍按剩余额度降序；总余量相同的组同月重建顺序一致、跨月顺序变化；月度切换后活动组回到排序后的首组。
